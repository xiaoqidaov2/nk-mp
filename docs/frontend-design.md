# 前端页面设计说明

## 视觉基调

中性商务后台风：浅灰背景（`#f4f6f9`）、白色内容区、单一蓝色主色（`#2f6fed`）加四个语义色。
不使用任何品牌 Logo、字体或品牌色，页脚固定声明「非官方，仅信息聚合」。
表格行高约 36–40px、字号 13px，信息密度优先；卡片仅用于状态区，数据区首屏即表格。

## 状态视觉

| 状态 | 符号 | 底纹 | 文字 |
|---|---|---|---|
| 有货 | ★ | 浅绿 | 显示实付价，缺价时显示「待补价」 |
| 无货 | ✗ | 浅灰 | 无货 |
| 不售 | — | 浅橙 | 不售 |
| 未探测 / 不可信 | ? | 灰色斜纹 | 未探测 |
| 缺少尺码结构 | ! | 浅红 | 无尺码结构 |

状态同时用符号、文字与底纹表达，不依赖颜色；「未探测」的斜纹底必须在视觉上与「无货」区分。

## 页面

| 路由 | 页面 | 关键内容 |
|---|---|---|
| `/login` | 登录 | 邮箱 + 密码，错误就地提示；账号由管理命令创建 |
| `/dashboard` | 概览大盘 | 凭证状态、数据新鲜度、配额用量、八项统计、近两日变化 |
| `/tasks` | 监控任务 | 任务列表、启停、立即扫描、最近扫描列表 |
| `/tasks/new` | 创建向导 | 四步：货号（粘贴/选择）→ 门店（可全选）→ 周期与提醒 → 确认 |
| `/tasks/:taskId` | 任务详情 | 任务配置、门店与货号链接、该任务的扫描记录 |
| `/scans/:jobId` | 扫描详情 | SSE 进度、成功/失败/未探测计数、逐店结果与失败原因、仅重试失败门店 |
| `/stores/:storeCode` | 单店视图 | 门店信息、已监控结果、本店近 14 天变化；固定说明「非全店清单」 |
| `/styles/:styleCode` | 货号矩阵 | 门店 × 尺码矩阵、尺码筛选、仅有货门店、价格与促销明细 |
| `/changes` | 变化流水 | 按类型筛选、状态前后值与价格变化、跳转矩阵高亮单元格 |
| `/account` | 账户与配额 | 当前账号、今日配额进度、凭证状态、数据能力边界表 |
| `/ops` | 服务方后台 | 凭证续期、门店同步、服务健康、租户列表 |

## 交互约定

- 任务进度优先使用 SSE，连接失败自动回退为 3 秒轮询，并显示连接状态。
- 顶栏与卡片统一使用日期时间格式 `YYYY-MM-DD HH:mm:ss`，时区 `Asia/Shanghai`。
- 所有数据展示「最近探测」相对时间，hover 显示绝对时间；超过 2 小时标记「数据已陈旧」。
- 小于 768px 进入只读卡片布局；移动端不提供批量粘贴、全国扫描创建与导出。
- 危险操作（删除任务、停用账号）需要二次确认。
